今天的主线是「本地 Agent 栈一起到货」：蚂蚁百灵放出 560B/25B 激活的 Ling-3.1-flash；英伟达把专为本地智能体打的 Nemotron 3.5 Bolt 定在今天开源，PAIR 同步出 beta；Hermes Agent v0.22 把无密钥上手、一键本地模型和 Connectors 打成一条安装路径。另有 Anthropic 给 Claude Platform 开 OTel 追踪，以及一篇证明开源指令模型用字母 logit 读出就能逼近（乃至超过）闭源决策模型 Jev 的论文。

模型 Models

模型蚂蚁百灵 Ling-3.1-flash：560B 总参数、25B 激活，混合线性 MoE，MIT 开源，首日接 SGLang / vLLM

inclusionAI（蚂蚁百灵）10 月 14 日晚放出 Ling-3.1-flash，定位为面向复杂真实任务的原生混合推理升级。架构是混合线性 MoE：63 层 KDA + 9 层 Gated MLA（约 7:1），另有 4 层稠密层；512 个路由专家、1 个共享专家，每 token 激活 8 个专家；隐藏维 4096、注意力头 64。官方称总参数约 560B、每 token 激活 25B，并给了超长上下文（中文报道写 1M；部署文档侧也出现 262K 口径，以模型卡为准）。

能力侧重通用智能体、搜索、办公与软件工程，评测口径覆盖 GDPVal-AA、HealthBench、FrontierSWE、Terminal-Bench、SWE-bench Pro、AutomationBench、MCP-Atlas 等。部署首日 SGLang 镜像含 MTP 投机解码与 Hopper 优化（示例 8×H200 TP8+EP8）；vLLM 也有配方。权重已上 Hugging Face / ModelScope / OpenRouter，MIT 许可。对构建者：这是「超大稀疏 + 长上下文 + 编程/Agent 基准」路线的又一次国产开源推进，但 25B 激活仍意味着多卡部署门槛不低。

来源：Hugging Face · inclusionAI/Ling-3.1-flash · 读懂AI时代（2026-10-14） · SGLang Cookbook · vLLM Recipes

模型NVIDIA Nemotron 3.5 Bolt 74B：74B-A9B、2-bit 塞进约 24GB，今天发布；PAIR 1.0 同步出 beta

英伟达在 10 月 13 日博客里预告：Nemotron 3.5 Bolt 74B-A9B 24GB 于周四（10 月 15 日）发布，专为 RTX Spark 上的本地智能体设计。MoE 总量 74B、每 token 激活约 9B，用量化感知训练的 2-bit 压缩到约 24GB；官方自称比多数同显存足迹的稠密模型更快、比多数同级 MoE 更「聪明」——均为厂商口径，独立评测尚未到。发布即支持 llama.cpp、vLLM、Ollama、Unsloth、LM Studio，并直连 Hermes、OpenClaw；权重、训练数据与配方全部开源。

同日生态里，个人 AI 路由器 NVIDIA PAIR 正式脱离 beta：自动发现局域网机器、装推理引擎、跨机分发负载，新增 llama.cpp、Hugging Face 直连下载与 RTX Spark 支持，Windows / Linux / macOS 可用。RTX Spark 笔记本定于 10 月 16 日开售；更小的 Bolt E4B（4GB，面向 ACE 游戏角色）排在 10 月 23 日。对构建者：这是「本地 Agent = 模型 + 路由 + 沙箱」打包卖硬件的一天，质量与 Arm Windows 兼容性仍需实测。

工具与可观测性 Tools & Observability

工具Hermes Agent v0.22.0「Threshold」：无密钥引导上手、一键本地 llama.cpp、Connectors，代码库瘦身约 34%

Nous Research 于 10 月 14 日（UTC）发布 Hermes Agent v0.22.0。新装桌面端会先跑一段引导聊天，用一次性免费试用模型 nous/welcome，不必先配 API Key；Connectors 让 Agent 经 Nous 网关操作 Linear、Notion 等托管应用，并可把托管应用与 MCP 收进同一页；本地模型路径一键安装维护 llama.cpp（CPU/CUDA/Metal/Vulkan/ROCm），只推荐能整模放进 GPU 显存的候选，并支持任意 Hugging Face GGUF。

工程侧：默认跟随经过 CI / Docker / 签名桌面包验证的 SemVer 稳定通道；Windows 改为签名 MSIX（含 Microsoft Store），macOS Apple Silicon 公证；新的 hermes pm 用哈希校验的环境世代切换，避免半更新。插件目录扩到约 600 个已审条目；源码从约 106 万行降到约 69.8 万行。升级注意：托管运行时升到 Python 3.14，Windows 桌面仅 MSIX 且需 Win11 22H2+。对构建者：这是本地 Agent 产品把「能跑起来」当成一等公民的一版，而不是又堆一堆模型名。

来源：GitHub Release v0.22.0 · AICoder（2026-10-14）

工具Anthropic：Claude Platform 公测导出 OpenTelemetry 追踪，Managed Agents / Messages API / SDK 统一进你的可观测栈

Anthropic 10 月 14 日宣布，Claude Managed Agents、Messages API 与 Claude SDK 可将 OpenTelemetry 追踪发到任意 OTel 工具。在 Claude Console 配一个目的地后，每个 Agent 回合、模型调用与工具调用会以标准 trace 出现，带延迟、token 与 ID；语义遵循 OpenTelemetry GenAI 约定，可与 Grafana、Honeycomb、Sentry、Langfuse、LangSmith、Datadog 等并排调试。

对构建者：生产 Agent 的瓶颈往往是「看不见哪一步慢/错」，原生 OTel 少写一层自定义埋点；Managed Agents 与 Messages API 需在 Console 配 HTTPS OTLP 目的地（需管理员权限），SDK 侧可自动导出。这是把 Agent 行为接进现有 SRE / eval 流水线的一步，不是新模型能力。

来源：Claude Platform 文章（2026-10-14） · OpenTelemetry 文档

研究 Research

研究Releasing the Inner Jev：开源指令模型用字母 logit 单次前向即可做决策；短 LoRA 后 Gemma 4 31B 超过闭源 Jev

哈佛 / Kempner 的 arXiv 2610.17205 研究「System One」决策模型：给定状态、问题与选项，一次前向返回各选项概率，不做文本生成。作者发现：把选项标成 A/B/C…，直接读最后位置上字母 token 的 logit，再温度校准，Gemma 4 31B 零样本在自建验证集 OpenDecisions（2,352 题）上 Capability 79.6，接近 Jev 的 80.1。

再加约 400 step 的 LoRA（约 5 GPU 小时）与从 LM head 字母行初始化的决策头，Gemma 4 31B 升到 84.4，并在 JevBench v1.7 上 81.5，超过 Jev。消融显示收益主要来自适配 backbone，而不是重训决策头。作者开源 Jeff-1.0 系列、服务代码与 OpenDecisions。对构建者：Agent 里大量「路由/是否调用工具/选哪条策略」不必每次生成长推理；开源底座已经能当校准分类器用，专用 RL 架构不是必要条件。

来源：arXiv 2610.17205
