模型 Models

模型上海 AI Lab 发布 Atria Dawn Preview：把 Agent 技能写进权重的 744B MoE

上海人工智能实验室发布 Atria Dawn Preview：基于 GLM-5.2（约 744B 参数 MoE、256K 上下文），面向科研与工程中的开放式任务，强调「分析 → 规划 → 写代码 → 跑实验 → 读错 → 重试」全闭环。训练侧用 Verifiable Experience Pipeline，把可执行环境里、可外部验证的工具交互写进权重，而不是只挂在外部脚手架上。权重以 MIT 在 Hugging Face / ModelScope 放出（含 FP8），配套 GitHub 与 API（api.atria-asi.ai）；输入目前为纯文本。

作者在 16 项真实研究 / 工程 / 数字工作基准上称与前沿 agent 可比，并在其中 5 项报最高分；模型卡表格里 BFCL v4 为 77.0，SWE-bench Pro 为 59.6（仍明显落后 Claude Opus 5 的 74.7）。论文 arXiv:2609.15818 还分析了 56 人、769 条人机协作任务记录：约三分之一完成任务被参与者评为「没有 AI 不可行」，同时最终决策仍多由人把关。对构建者：这是「技能内化进权重 + 立即开源权重」的一条可对照路径，但仍需在自己的沙箱与评测 harness 上复现，尤其是长程 coding agent 场景。

来源：arXiv:2609.15818 · HF · internlm/Atria-Dawn-Preview · GitHub · atria-asi/Atria-Dawn-Preview · mlllm.io（2026-09-20）

模型阶跃星辰 Step 5 Preview：600B / 激活 27B 的 Agent 旗舰，API 今日可用

阶跃星辰（StepFun）于 9 月 20 日宣布开放旗舰基座 Step 5 Preview：稀疏 MoE，总参约 600B、每次激活约 27B，原生最长约 100 万 token 上下文，支持文本与视觉输入，定位真实 Agentic 主模型。官方产品页与多家中文科技媒体同步报道：API / 产品侧即日可调用，完整权重计划约 10 月 15 日开源；对外报价口径约为每百万 input / output token $1 / $2.70，并称单任务成本约为 Claude Opus 5 的约八分之一（以厂商与媒体转述为准）。

公开材料还提到 Artificial Analysis Intelligence Index 约 44 分、开源阵营前列，以及长程实验（如 24 小时内核优化、自动后训练抬升 AIME24）等演示。对构建者：现在可先用 API 压真实 agent 工作流与成本曲线；是否自托管要等到十月权重与许可条款落地后再定，独立基准复现同样必要。

来源：StepFun · Step 5 Preview · IT之家（2026-09-20） · AIBase（2026-09-20）

模型Qwen-Image 2.1 静默开源：7B 统一生图/编辑，但许可改为研究用途

Qwen-Image 团队在 9 月 20 日把 Qwen-Image 2.1 权重放到 Hugging Face / ModelScope：视觉生成组件约 7B（32 层单流 DiT），配 Qwen3-VL 8B 文本编码器与 64 通道 RGBA VAE；支持原生透明图、最多约 10 张参考图、圈选/涂鸦/掩码局部编辑，以及 Diffusers / ComfyUI / vLLM-Omni / SGLang 等当日可用路径。同日还放出 PE-T2I / PE-I2I 两套提示词改写检查点（约 Qwen3.5-VL 9B），在进扩散模型前把模糊编辑指令改写成明确指令，并在系统提示里显式规定「画面内文字语言」的优先级。

关键变化：许可从早期 Qwen-Image 线的 Apache 2.0 改为 2026-09-20 的 Qwen Research License（非商业；商用需另申请）。目前几乎没有独立第三方基准，质量数字仍主要来自厂商材料。对构建者：适合本地评测与研究原型，不适合直接嵌进要商用发行的产品管线——先读 LICENSE，再决定是否投入工程。

工具 Tools

工具Google AX 发布 v0.3.0：声明式 Agent 编排器，按 Kubernetes 味道跑沙箱任务

Google 开源项目 AX（Agent Executor，仓库 google/ax）在 9 月 20 日打出 v0.3.0 标签。它用 ax.io/v1alpha1 清单声明 Task / Workspace / Gateway / Model：给 agent 预挂 Git、MCP 与 skill，用 Gateway 白名单锁出站网络，在 Agent Substrate 沙箱里按 CPU/内存限额跑长任务，并支持 ax apply、ax watch、ax ssh、ax suspend / ax resume。仓库仍标注概念与协议可能大改，属早期阶段。

对构建者：若你已经在用 K8s 跑批处理，这提供了一套把「会烧钱循环、会积累状态、需要隔离」的 agent 工作负载当作一等公民编排的词汇表；落地前先确认集群、镜像仓库与 Agent Substrate Control API 是否齐备，并按项目警告做好破坏性变更预案。

研究 Research

研究Zarya：同一架构联合优化自回归与掩码扩散，双模式推理

arXiv:2609.19868（约 9 月 17 日提交，周末前后仍在社区讨论）：提出 Zarya 混合语言模型家族，在单一架构里同时优化自回归（AR）与掩码扩散（MDM）目标。训练把数据切成可变大小 slot，并用课程从细粒度 AR 过渡到粗粒度扩散；推理提供两套接口——MDM 首击去噪采样，以及 slot 级推测解码（slot 间扩散选择 + slot 内自回归填充，可复用完整 KV cache）。训练配置与推理模式解耦。

作者公开 0.6B / 1.7B / 4B 权重，并宣称兼容 Hugging Face AutoModel / AutoConfig。对构建者：这是把「并行解码吞吐」与「AR 的 KV 复用 / 连贯性」放进同一检查点的一次明确工程化尝试；适合做解码范式对照实验，上下文长度仍偏短（材料中约 2K），不宜直接对标超长上下文生产模型。

产业与基础设施 Industry / Infra

产业Nvidia AI Infra Summit：把「每兆瓦产出多少 token」写成主指标

多方报道（约 9 月 20 日）称 Nvidia 在 Santa Clara AI Infra Summit 上把 AI 工厂叙事压到单一度量：tokens per megawatt。公司宣称 Vera Rubin NVL72 机架级系统相对前代可达约 30× 每兆瓦吞吐、大模型上约 35× 每兆瓦 token 吞吐，以及 agentic 负载上约 45× 更低的每百万 token 成本，并称 Vera Rubin 已进入全面生产。配套 DSX 栈拆成 MaxLPS（功率分配）、Max-Q（每瓦 token）、Flex（电网需求响应）；与 Silicon Valley Power 的试点曾把负载从约 4MW 自动降到 3MW 而不掉高优先级任务。

报道也提醒：对比基线在材料里有时写 GB300、有时写 GB200，客户侧（如 CoreWeave）复现倍数往往更小。对构建者与买方：扩容瓶颈常在互联与用电而非芯片本身；评标应要求在自己的模型、批大小与延迟 SLO 下复测 tokens/MW，并把 800V DC、柔性负荷与数字孪生蓝图当成可验证的交付项，而不是只看峰会幻灯片。

来源：Bytevyte（2026-09-20）

产业华为 CONNECT：电网友好型 AIDC，把 tokens per watt 写成设施层 KPI

华为在 HUAWEI CONNECT 2026 相关活动（媒体稿标注 9 月 20 日）发布 grid-interactive AIDC 方案：把 UPS、智能锂电与构网型储能做成可平滑 AI 负载波动、并对电网友好的设施层能力；同时强调液冷与模块化交付，目标表述为最大化 tokens per watt、最小化 cost per token。同场 SenseCore 等合作方发言将效率叙事从 PUE 推到端到端 TPW（tokens per watt）。

这与 Nvidia 同日的「每兆瓦 token」叙事形成对照：一边是加速器厂商用软件栈吃透固定功率包络，一边是设施与电力厂商把算力负荷变成可调度电网资产。对建设方：选型时要把供电架构、储能、液冷与调度协议写进同一张 BOM，而不是只比 NPU/GPU 峰值 FLOPS。
