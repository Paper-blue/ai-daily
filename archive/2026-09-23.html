过去约 24 小时的主线是「慢下来之后的价格战」：Anthropic 与 OpenAI 几乎同日放出更便宜的中坚模型；同时个人 Agent 的「人机混跑」、版权训练规则与进程级自进化评测也把系统层议题推到台前。

模型 Models

模型Anthropic 发布 Claude Opus 5.5：对齐 Fable 级能力，典型负载约降本 40%

Anthropic 于 9 月 22 日正式推出 Claude Opus 5.5，称其为 Claude 5.5 家族首发，并自称是公司呼吁「pace the frontier」之后的第一款发布。官方称多数工作可对标 Claude Fable 5.1，相对 Opus 5 典型负载运行成本约低 40%；API 标价为每百万 token 输入 $4 / 输出 $20（较 Opus 5 降约 20%），缓存读取 $0.20（降约 60%），默认设置下输出速度约快 30%+。模型 ID：claude-opus-5-5，已上线 Claude 平台及 AWS / Google Cloud / Azure。

厂商自评在 Terminal-Bench 4.0、FrontierCode、CursorBench、GDPval-AA 等 agentic coding / 知识工作基准上领先或接近旗舰；同时强调这是迄今自动化行为审计（alignment audit）表现最好的 Claude。因生物与网络安全能力接近 Mythos 5.1，部署了与 Fable 5.1 同级护栏：多数网络安全任务回退到 Opus 4.8，生物相关请求回退到 Opus 5，并开放 Life Sciences / Cyber Verification 申请通道。发布前经 Frontier Design、METR 等外部评测。Sonnet 5.5 / Haiku 5.5 预计数周内跟进。对构建者：可立刻用同题对比 Opus 5 / Fable 测真实 token 与步数；护栏回退会压低部分安全相关基准分，产品路径需按合规档位规划。

来源：Anthropic · Claude Opus 5.5 · The Verge（2026-09-22） · CNA

模型OpenAI 放出 GPT-6 Sol / Luna：相对 5.6 促销价 API 约降半，补齐 Astra 下的中坚档

OpenAI 于 9 月 22 日（约 Anthropic 发布 90 分钟后）上线 GPT-6 Sol 与 GPT-6 Luna，补齐本月初 GPT-6 Astra 之下的中低档。官方口径：Sol 面向复杂编码与 agent 工作流，Luna 面向摘要、抽取、快问等「目标清晰的高吞吐任务」；API 名称分别为 gpt-6-sol / gpt-6-luna。多家报道称标准 API 价约 Sol $2/$10、Luna $0.10/$0.50 每百万 input/output token，相对 GPT-5.6 系列促销价约降 50%，归因于缓存与推理效率提升；上下文窗口报道约 105 万 token。

可用性：ChatGPT Work 与 Codex 面向 Plus / Pro / Business / Enterprise / Edu；API 同步开放；Free / Go 可在桌面端试用 Luna，主站 Chat 面则逐步放量。OpenAI 称内部事实性评测上 Sol 错误约为前代一半，并达到接近 Astra 的可靠性（厂商自评）。对构建者：这是「旗舰能力下沉 + 单价下探」的直接信号——应用侧应重测同等任务完成成本，而不是只看每百万 token 标价；与 Opus 5.5 的对标应锁定同一 harness 与同一题集。

来源：TechCrunch（2026-09-22） · The Verge · CNBC · OpenAI Developer Community

产业 Industry

产业Meta Muse「电话代办」内部测试接入人工坐席：披露与隐私争议升温

404 Media 与 Reuters（经 CNA 等转载）于 9 月 22 日报导：Meta 个人 Agent Muse 近期对外宣传可代用户给商家打电话（订餐、预约等），但内部 dogfood 已加入「human agent / human concierge」层——由受训承包商接手部分通话并完成请求。内部帖称 Muse「不再独自工作」，可把请求交给人工坐席；部分员工担心敏感信息进入呼叫中心，且测试者未必事先知情通话由人完成。

Meta 发言人称这是正式公开发布前的内部测试，目的是收集反馈以完善安全与隐私保护，并称只会在准备就绪且有适当披露时推出。对构建者：这是高权限个人 Agent 产品化的现实切片——语音外呼、电话树导航与商家协商仍常需人机混跑；产品契约必须把「何时转人工、谁听到什么、如何默认关闭」写成可审计策略，而不是事后公关。

来源：404 Media（2026-09-22） · CNA / Reuters

产业OpenAI / Anthropic 吁澳大利亚放松 AI 训练版权限制：主张「有条件窄豁免」

路透社系报道（CNA 9 月 22–23 日更新）：OpenAI 与 Anthropic 向澳大利亚议会 AI 相关调查提交意见，呼吁重新考虑禁止用当地创意内容训练模型的路径。澳大利亚政府已排除宽泛的文本与数据挖掘版权例外；Anthropic 提出可用「窄口径有条件批准」替代，并表示若附加投资或支持本地创作者等条件可予考虑；OpenAI 则主张允许模型从公开可用信息学习、同时给权利人协作机会。

两家公司均把议题与在澳数据中心投资挂钩（如 OpenAI 与 NextDC 悉尼项目、Anthropic 参与昆士兰数据中心合作）。议会联合特别委员会报告预计 11 月提交。对构建者：训练数据合规正从「原则声明」进入东道国投资—版权—算力绑定的实务谈判；出海训练与本地化部署需同步评估版权例外是否存在、以及有条件许可的合同成本。

来源：CNA（2026-09-22） · Reuters

产业Google / DeepMind 成立 DeepMind Institute：公开 AGI 政策论文，Hassabis 提前沿评测机构构想

多家 9 月 21–22 日报道称，Google 与 Google DeepMind 推出 DeepMind Institute，由 Shane Legg（执行主编）、James Manyika、Demis Hassabis 等担任董事，意图把 AGI 讨论从通稿推进到可争辩的长文。首批议题覆盖 AGI 经济冲击政策、保持模型推理可监控性，以及前沿模型评测框架。Rohin Shah 与 Anca Dragan 等主张「推理不透明并非必然」，呼吁限制不透明串行计算或要求证明系统仍可监控；Hassabis 提出美国主导的前沿 AI 标准机构构想——初期自愿、最先进模型发布前最长约 30 天送审，成熟后或可成为美国部署前提，并预留风险升高时的协调减速条款。

对构建者：这与本周「pace the frontier」叙事同向，但落到可检验的披露与评测机制；关注后续文集是否把标准机构从散文推进到立法/标准文本，以及它对发布窗口与外部红队节奏的实际影响。

研究 Research

研究EvoPathBench：用检查点冻结伪影，做自进化 Agent 的进程级能力评测

arXiv:2609.24663（2026-09-21 提交）提出 EvoPathBench：针对会把交互反馈写成持久记忆/技能等伪影、并据此改变后续决策的 self-evolving agents。作者认为只看终点成绩不够，需要在经验流上追踪「某能力何时出现、后续更新是强化、保持还是削弱」。方法固定基座模型与工具，在一系列检查点冻结演化中的伪影，再在留出 episode 上评测目标能力。

基准用公开交易数据与校准轨迹，覆盖未见任务泛化、无关学习后的保持、以及新证据下的规则适应。结果摘要：相近未见任务上的增益常在分布偏移下变弱；保持损失集中在少数演化路径；尚无方法可靠完成规则适应；自进化能生成留出集增益显著的候选伪影，但最终选中的更新往往吃不满这一潜力。对构建者：若你在做 memory/skill 自更新循环，应把候选生成与选择拆开评测，并记录能力曲线而不只报最终分数。

来源：arXiv:2609.24663
