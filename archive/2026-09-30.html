模型 Models

模型OpenAI DevDay：GPT-6.1 Sol 以约 1/5 Astra 价逼近其编码与计算机使用能力

当地时间 9 月 29 日 DevDay，OpenAI 发布 gpt-6.1-sol（距 GPT-6 Sol 仅约一周）。官方称其在 agentic coding、computer use 与专业工作上接近 GPT-6 Astra，标准输入/输出 token 价约为 Astra 的五分之一；API 标价约 $2 / $10 per 1M input/output（缓存输入更低）。相对 GPT-6 Sol，公司报低 reasoning effort 下事实错误率从 11.4% 降至 7.7%，并在遵循限制、标记坏掉的搜索工具等方面更稳。

GPT-6.1 Astra 仍未随 DevDay 发布（延续昨日安全搁置）。Sol 已对 Plus / Pro / Business / Enterprise / Edu 开放 ChatGPT Work 与 Codex，暂未进普通 Chat。对构建者：在「最强模型因对齐不过关停发」窗口里，Sol 成为默认工作马——选型应对照 Astra Ultrafast（付费加速档）与 Agents API 一并评估，而不是只看榜单峰值。

来源：TechCrunch（2026-09-29） · OpenAI API · gpt-6.1-sol · OpenAI Developer Community 汇总

模型Anthropic Claude Sonnet 5.5：Terminal-Bench 4.0 跃至 70.6%，首款带 cyber 护栏的 Sonnet

Anthropic（9 月 28 日官网）发布 Claude Sonnet 5.5：相对 Sonnet 5，生成速度约快 30%+，同价位下多数任务成本可低至约 30%（$2 / $10 per 1M in/out）。Terminal-Bench 4.0 报 70.6%（Sonnet 5 为 10.3%；Opus 5.5 为 66.4%¹），CursorBench 4.0 55.5%，OSWorld 2.1 partial 80.1%；GDPval-AA 接近 Opus 5.5。API 模型名 claude-sonnet-5-5，已上 AWS / GCP / Azure；关闭 thinking 时需改用新的 between_tools 设置。

因 cyber 能力接近 Opus 5，这是首款以 Opus 级 cyber 护栏与 fallback 上线的 Sonnet；亦首次为 Sonnet 加上防蒸馏分类器与扩展的 preserved thinking。对构建者：中端「日常编码 + 文档/幻灯」档性价比曲线被重画——高 effort 可逼近 Opus，低 effort 则以更低成本吃掉原 Sonnet 工作量；迁移时务必核对 thinking / tool 配置，避免 silent behavior 变化。

来源：Anthropic · Introducing Claude Sonnet 5.5（2026-09-28）

模型NVIDIA Kumo Tabular：纯人工合成表预训练的开源表格基础模型上架 HF

NVIDIA（9 月 29 日 Hugging Face Blog）发布 Kumo Tabular（OpenMDW-1.1）：给定带标签的上下文行，单次前向即可做分类/回归，无需微调与特征工程。模型 28M–215M 三档，仅在 SCM 生成的合成表上预训练（Small/Medium/Large 约见 3500 万 / 7100 万 / 1.37 亿张表），声称在 TabArena、BeyondArena、TALENT、ScoringBench 上整体排名第一，并在统一 RTX 6000 Pro 评测下比 LimiX-2 快约 17×。

推理走开源库 structured-data-models（GitHub + HF weights）。局限：仅数值/类别列；单次前向最多 10 类（库用 ECOC 扩展多类）。对构建者：企业表格任务从「每任务重训 GBDT」转向「上下文学习式表格 FM」的开源选项变实——接入时仍需在自有 hold-out 上校验校准与分布偏移。

来源：Hugging Face Blog · NVIDIA Kumo Tabular（2026-09-29） · GitHub · structured-data-models · HF · nvidia/Kumo-Tabular

工具与平台 Tools

工具OpenAI Dots：GPT-6 Astra 驱动的 always-on 个人 Agent，自带云电脑

DevDay 同期推出 Dots：由 GPT-6 Astra 驱动的持久 Agent，各自配备云电脑，可连接 4000+ 应用，在后台跨项目推进任务；入口含 ChatGPT、Slack、Microsoft Teams（含语音），短信后续开放。Pro / Business Premium 在部分市场首发；Enterprise / Edu / Healthcare 可由管理员开启 beta。企业侧预览「specialist dots」（独立身份与系统权限），并计划接入 Microsoft Agent 365 治理。

首个 Dot 不另收费，但 Work / Codex 任务仍计入套餐额度。对构建者：产品形态已从「对话里临时工具调用」转向「长期驻留、可主动打扰、可跨应用持上下文」——权限模型、审批闸门与跨端会话隔离将成为集成重点；亦直接对标 Meta Muse。

来源：TechCrunch（2026-09-29） · The Verge · CNBC DevDay 直播更新

工具Agents API 公测 + Codex 可复用云环境 / Security Cloud

OpenAI 将 Agents API 推入 public beta：托管 Codex harness（会话、编排、上下文压缩与恢复），支持代码执行、MCP、多 Agent 委派，以及 hosted browser 的 computer use。另与 Amazon 推出 Bedrock Managed Agents（推理与数据留在 AWS）。Codex Cloud 增加可复用开发环境（仓库、依赖、工具与权限配置可共享复用）；CLI 加入双向语音与 /agents 视图；ChatGPT 桌面端 Code Review 与 Codex Security Cloud（按需/定时扫 GitHub 仓并准备修复，含 Daybreak Blue 模型通道）一并亮相。

配套还有 Decisions API（Luna，预定义选项上的快速决策，limited preview）与 Pro 500（$500/月，含 Astra Ultrafast）。对构建者：托管 harness + 持久云环境意味着「本地 CLI 一次性沙箱」不再是默认——要单独设计密钥注入、环境审批与 Security Cloud 扫描策略。

来源：OpenAI · Introducing the Agents API · TechCrunch · Codex Cloud（2026-09-29） · DevDay 资源汇总

工具Hugging Face Serge：夜间 CI Agent 80 天合入 29 个 Transformers 修复

Hugging Face（9 月 29 日 Blog）详解内部 CI Agent「Serge」：每晚筛选持续失败的集成测试 → GPU 复现 → 查重（relore 仓库记忆）→ 生成补丁 → 未打补丁/已打补丁各跑 5 次验证 → 仅在全部通过后开 PR。短寿命 K8s pod 无集群凭证，仅能推 serge/ 分支；约 80 天内 29 个修复合入主线（约 2.5/周）。近两周漏斗：117 组失败中仅 24 组产出经验证的 PR 事件。

推理主要用 Kimi K-2.7-Code，单会话约 $2–3；估约 $14/PR、$43/合入 PR。对构建者：价值不在「让模型写更多 diff」，而在「可丢弃的验证漏斗」——复现门槛、只改期望值时的 reward-hacking 怀疑、基础设施超时不当成成功信号，才是无人值守修虫的可迁移模式。

来源：Hugging Face Blog · Anatomy of a bug-fixing agent（2026-09-29）

研究 Research

研究Google Research 开源 RRSI：正则化递归自我改进 Agent harness

Google Cloud AI Research 联合 UNC / Stanford / WashU（报道日期 9 月 29 日）开源 RRSI（Regularized Recursive Self-Improvement，Apache 2.0）：冻结模型权重，让 Agent 改写自身 harness（prompt、工具、记忆、控制流、子 Agent）。针对「在 evolve set 上过拟合」引入 annealed 编辑预算、泄漏批评器、噪声地板、成本规则与剪枝——增益须跨过基线方差，额外 token 须被实测收益买单。

报告称 Claude Opus 4.8 上 Terminal-Bench 2.1 从 74.2%→80.2%；从未参与选择的 SWE-bench Verified 从 82.0%→83.8%；多个 OOD 集亦为正。代码：github.com/google-research/rrsi。对构建者：与「Growing Harness / 把控制沉到代码」同向——自我改进循环本身需要正则化，否则榜上涨分不等于可迁移产品能力。

来源：MarkTechPost（2026-09-29） · GitHub · google-research/rrsi

产业 Industry

产业Meta Muse for Small Business：Shopify / Slack / QuickBooks 等连接器落地

Meta（9 月 29 日 About 博客）宣布 Muse for Small Business：在既有 Muse Agent 上扩展技能与连接器，覆盖 Shopify、Slack、Dropbox、Asana、Box、Canva、Figma、Intuit QuickBooks、Stripe、Zoom 等，以及 Instagram 专业号、Facebook 主页与 Meta 广告账户；官方强调发布/发送/花费需用户批准。多数场景免费（有用量上限），更高用量走订阅。

此举紧接 9 月 28 日 Meta Enterprise Platform（Muse API / Muse Code 等）发布。对构建者：消费级 always-on Agent 正用「业务系统连接器 + 审批闸门」切小微经营场景；与 OpenAI Dots 同期对打——集成评估应看连接器深度、品牌上下文与动作审批，而非只比对话演示。
