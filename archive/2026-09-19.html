产品与安全 Products / Safety

产业Meta Muse：假设提示注入会成功，用 OS 级 harness 兜底的个人 Agent

DeepLearning.AI The Batch（9 月 18 日）梳理：Meta 个人 Agent Muse（基于 Muse Spark 1.3）可经 App / WhatsApp 读发邮件、浏览、填表、经 Stripe Link 下单，并在 App 关闭后继续后台运行。每个 Agent 跑在独立 Linux VM 上；工作区与工具关在运行时 cell 内，凭证与连接器在 cell 外。模型只见替身 token，真正凭据由 Sentinel 在出站时注入；发信与支付必须用户确认，且确认走系统对话框而非会话消息，避免注入伪造批准。

防御还包括：入站数据标为不可信、cell 外分类器筛工具输出、浏览器子代理读无障碍树而非页面 DOM/JS。设计呼应 CaMeL（规划与读不可信数据分离）与 Willison「致命三件套」（私有数据 + 不可信内容 + 外发通道）。对构建者：高权限 agent 应默认「模型会被骗」，把容器逃逸、凭证零持有与不可被模型覆写的闸门做成硬约束；Meta 称将开源 Muse Spark 权重，但更值得期待的是 harness 本身。

来源：DeepLearning.AI The Batch（2026-09-18）

模型与开源 Models / Open Source

模型Xenon 开源 Hunmin VLM 397B：8×B200 后训练的 computer-use 大模型

韩国 Xenon（9 月 18 日）宣布基于 Qwen3.5-397B 开源 Hunmin VLM 397B：强化屏幕 grounding 与桌面操控，可定位按钮/输入框并在真实电脑上执行任务。ScreenSpot-Pro 准确率 75.6（Hugging Face 官方榜第二）；Linux OSWorld 70.5，较基座高 22.3 分；WindowsAgentArena 亦高于基座约 9.1 分。韩语八项基准与基座差距控制在约 2 分内。

后训练路径：低秩迁移公开 computer-use 能力，再在 FP8 量化环境做 SFT 与 RL，全程仅用 8 张 NVIDIA B200。Apache 2.0 发布原版与约一半体积的 FP8 版，并公开评测方法。对构建者：这是「在已有超大开源底座上廉价加 computer-use」的可复制范例，重心从堆参数转向能力增量与可部署性。

来源：Seoul Economic Daily（2026-09-18） · DigitalToday

模型Project Norn V18：9B 混合线性注意力本地推理模型（含可复现基准包）

Osakra Research 在 Hugging Face 发布 Project Norn V18（约 9B，面向消费级本地）：强调混合线性注意力与紧凑推理，宣称可在 <5.8 GB 活跃显存、单机 RTX 4070 级环境满 GPU 卸载运行。仓库捆绑约 1,000 题 held-out 综合压测（含 GSM8K / MMLU / CodeAlpaca 锚题与大量程序化生成探针），自报 micro/macro 综合准确率约 81.8% / 80.6%。

对本地与开源社区：价值在于「模型 + 可审计基准包」一起发布，便于复现而非只晒排行榜截图；具体架构细节与外部第三方复测仍需自行核验 README 与权重许可后再接入生产。

研究 Research

研究Zarya：同一架构联合优化自回归与掩码扩散，双模式推理

arXiv:2609.19868（9 月 17 日）提出 Zarya：在单一架构内联合优化自回归（AR）与掩码扩散（MDM）目标。训练把数据切成可变大小 slot，并用课程逐渐加粗粒度，从细粒度 AR 平滑过渡到粗粒度扩散。推理提供统一接口下的两种范式：(i) MDM 采样（first-hitting denoising）；(ii) slotted speculative decoding——槽间扩散选择 + 槽内自回归填补，并可完整复用 KV cache。

训练与推理配置完全解耦；作者公开 0.6B / 1.7B / 4B 模型，并支持 Prefix Completion、Fill-In-the-Middle 等噪声模式。对「扩散并行解码 vs AR 连贯性/缓存」的长期张力，这是一条可落地的混合路线。

来源：arXiv:2609.19868（2026-09-17）

研究Abstract Token Curriculum：无监督连续「思维」表示的课程学习

arXiv:2609.19717（9 月 17 日，Gatmiry / Ghosh / Bartlett 等）提出 Abstract Token Curriculum（ATC）：通过逐步抬高问题难度的分布序列，让模型在连续表示空间形成内部抽象「thoughts」，无需显式思维链 token 监督或手工 scratchpad。理论部分对单层 softmax 注意力学 parity 给出分析；实验覆盖图可达性与算术任务。

相对依赖标注 CoT 的推理训练，ATC 把「中间计算」推到连续表征，对数据稀缺或任务特异 scratchpad 难设计的场景是一条值得跟进的无监督路线。

来源：arXiv:2609.19717（2026-09-17）

研究PARSER：并行读文档、串行加深推理的长上下文 Agent

arXiv:2609.06702（9 月 6 日投稿，近期仍在社区讨论）：PARSER 把「读」与「推理」解耦——轻量子代理并行读各 chunk，主代理经多轮 scatter–gather 广播查询、聚合证据并加深追问；可学习行为集中在 RL 训练的主代理，子代理冻结。在 7K–896K token 多跳 QA 上，4B 骨干平均优于最强串行记忆基线 5.7 分（896K 处 +12.0），并称推理延迟最高可降约 11×。

对长文档 agent：证据位置/顺序扰动下更稳，且避免「读越长、延迟线性涨」的耦合；适合作为 RAG/agent 编排的架构参考。

来源：arXiv:2609.06702

工具与基建 Tools / Infra

工具Flyweight：单卡 + 系统内存跑超显存 MoE 的开源推理引擎

社区报道（约 9 月 18 日）：开源 C++/CUDA 引擎 Flyweight 面向「专家层装不下单卡显存」的 MoE（如 Qwen / DeepSeek-V4 / Gemma 等），把溢出专家放到系统 RAM，并提供兼容 OpenAI/Anthropic 风格的 API 与聊天 UI。首版面向消费级 NVIDIA，作者征集 AMD / macOS 与 CPU expert kernel 贡献。

对本地部署：这是「一张卡 + 大内存」跑大 MoE 的实用路径；具体包名、许可与复现数字请以作者仓库/发布帖为准再接入流水线。
