周末窗口新闻偏少，主线是「给 Agent 装上判断和编排层」：微软发布只打分、不生成文本的 Microsoft-Decision-1，Nace 开源同类的 Drex v1.5；Anthropic 让 Managed Agents 自己写多 Agent 工作流，Google 推出企业级 Gemini agent。另有清华深研院开源「外部验证才准提交」的 VeriLoop E2，一篇论文证明跨模态对齐可以完全不用配对数据，以及 26 位学者提出用「只能推理的芯片」来硬性暂停前沿训练。

模型 Models

模型决策模型再添两员：微软 Microsoft-Decision-1 进 Foundry，Nace 开源 9B 的 Drex v1.5

微软 10 月 9 日发布 Microsoft-Decision-1：在 Qwen3.5-9B 上后训练，给定一组固定选项，一次前向就返回每个选项的校准概率，支持是非题、多选、打分和按 rubric 评判 Agent 动作，不生成解释、只收文本，上下文 32K。微软称在 36 个训练时未见过的基准（近 15 万题）上准确率最高，P50 延迟约为 GPT-6 Sol 的 1/35；把同一请求做 8 种改写扰动，平均只有 1.3% 会改变判断，打乱选项顺序时零翻转。已上线 Foundry 和 OpenRouter，输入每百万 token $0.042，输出免费；微软表示之后会换到 MAI 和 OpenAI 的模型上重训。

同一周，Nace.AI 在 Hugging Face 放出 Drex v1.5（约 9B，基于 MiMo-V2.6-Distill-Qwen-9B，Open RAIL-M 许可），兼容 TypeSafe 的 /v1/systemone 接口，自报在公开 Decision Index 0.3.1 上得 58.08，是 10B 以下最高，与闭源 Jev 1.13.0（57.96）处于同一误差带；Q8_0 GGUF 约 9.5 GB，可在 Apple 芯片或 CPU 上跑。对构建者：路由、审核、Agent 动作把关这类高频判断，现在有了便宜的托管和可自部署两条路，但分数都是厂商自测，上线前要用自己的数据检查置信度是否真的校准。

模型VeriLoop E2：清华深研院开源 27B 推理模型，「模型只提议，外部验证器决定能不能提交」

清华大学深圳国际研究生院机器人实验室以 Apache 2.0 发布 VeriLoop E2，基于 Qwen3.8-27B 后训练，面向代码、数学和物理，原生上下文 262K。核心机制叫 VeriLoop-Governed Recurrence（VGR）：模型负责提出候选、诊断和重新规划，外部的确定性验证器负责判断；只有在受保护的证据指标「不退步且至少一项严格变好」时才提交新状态，否则回滚到上一个已验证状态。

团队同时放出从 BF16 到 IQ1_M 的完整 GGUF 量化梯度和逐题评测证据数据集，自报 SWE-bench Pro 76.2%。需要注意的是，论文里用的生产级 harness 没有开源，部分 Agent 类分数依赖这个 harness，单独跑权重未必能复现。对构建者：「提交权交给验证器」这条规则本身很容易套到自己的测试或校验器上，比只看模型自报的推理过程更可靠。

来源：Hugging Face 论坛发布帖 · Hugging Face 模型页 · 评测证据数据集

模型HeyGen Voice：HeyGen 首个自研 TTS 模型，登上 Artificial Analysis 声音克隆榜第一

数字人公司 HeyGen 10 月 9 日发布自研语音模型 HeyGen Voice，首发即排在 Artificial Analysis 的 Controlled Voice（声音克隆）盲测榜第一。它和 HeyGen 的 Avatar V 数字人模型在同一套技术栈里，形象和声音来自同一处，平台和 API 内免费使用；另有每月 $99 的专业声音克隆附加项，需要本人明确授权，用 30 分钟到 3 小时的录音训练。

官方材料是付费新闻稿，没有给出架构或延迟细节。对构建者：做视频或配音产品时，克隆音质的头部差距正在缩小，选型时值得同时看授权与防冒用机制，而不只看榜单排名。

工具与平台 Tools

工具Claude Managed Agents 支持「动态工作流」：Agent 自己写程序，分阶段调度多个 Agent 再汇总

Anthropic 10 月 9 日在 Claude 平台更新中加入动态工作流（beta）：遇到「审阅几百份文档」这类可拆分的大任务，Agent 可以写出一个工作流程序，分阶段并行跑许多子 Agent，再合并结果，并在后台运行。开启方式是在 Managed Agents 的 multiagent 配置里打开 workflows，并带上 managed-agents-2026-04-01 beta 头。

同一批更新里还有两点和安全相关：受限网络的云环境，其 allowed_hosts 现在也作用于 web_search 和 web_fetch；SDK 新增 browser use / computer use 工具类，开发者接自己的自动化后端，由 SDK 负责工具循环、URL 策略和审批回调。对构建者：编排逻辑从「人写死」变成「模型现写」，更需要提前把网络边界和审批点配好，这也正好呼应昨天日报里 Anthropic 的越界行为报告。

来源：Claude 平台文档 · Multiagent orchestration · Claude 平台更新记录汇总（2026-10-09）

工具Google Cloud 推出 Gemini agent：一个能跨 Workspace、Microsoft 365、Slack 干活的企业 Agent

在 10 月 8 日的 Gemini at Work 2026 上，Google Cloud 发布 Gemini agent，定位是「工作通用 Agent」：给目标而不是步骤，它会规划、调用技能和工具、连接企业系统，把成品交回到文档、邮箱和开发环境里。可以拆出临时子 Agent 并行处理多步任务，也可以建成长期「同事 Agent」，拥有自己的 Workspace 账号、邮箱和日历，在云端持续运行；底层会在 Gemini 和 Anthropic Claude 等模型间按任务路由，并支持按项目设置花费上限。

目前是私有预览，官方 FAQ 标明后台多步委派、移动和桌面端、第三方模型选择仍属早期访问，也没有公布 API 规格和价格。对构建者：大厂企业 Agent 都在往「独立身份 + 多模型路由 + 预算闸门」靠拢，自建 Agent 平台可以参考这套治理设计。（10-09 日报未生成，此条为补收。）

研究 Research

研究「共享几何就是罗塞塔石碑」：不用任何图文配对，也能把独立训练的视觉和语言模型粗对齐

来自 TUM、ETH、MIT 等机构的论文（Phillip Isola 参与）检验「柏拉图表示假说」的一个强推论：如果不同模态的模型会收敛到相似的表示几何，那对齐时还需要配对数据吗？作者用 Wasserstein Procrustes 方法，先分别聚类两个嵌入空间、按 CKA 匹配簇中心得到粗对应，再交替做样本匹配和正交映射更新，全程不看一对图文。

在 7 个视觉模型、3 个语言模型上，平均 FOSCTTM 从此前方法的 0.223 降到 0.154（0.5 为随机）；不用任何分类数据，CIFAR-10 零样本 Top-1 平均 47.4%。两个空间的 CKA 相似度能很好地预测对齐是否会成功，规律在生物、医学、神经科学等 7 个领域都成立；只给 20 对样本时误差比最强基线低 14 到 28 倍。对构建者：配对数据稀缺的新模态（科学数据、传感器）可以先用这种几何方法打底，再用很少的标注样本精修。

来源：arXiv 2610.09411 · 项目主页

政策 Policy

政策26 位学者发布 200 页报告：用「只能推理、不能训练」的芯片，硬性暂停前沿 AI 训练至少十年

UC Berkeley 的 Will Fithian、Wesley Holliday 牵头，Stuart Russell、Barry Eichengreen 及普林斯顿、斯坦福、哈佛、牛津等校学者参与，10 月 9 日发布《The Feasibility of a Hardwired Pause of Frontier AI Training》。方案核心是利用高度集中的芯片供应链：停产可训练的 AI 芯片，逐步用硬件层面就限制了训练能力的「仅推理芯片」替换存量，让现有模型继续提供服务，同时配套国际互查机制，防止暗中训练或公开毁约。

报告认为如果各国愿意合作、交出或转移暂停前的存量芯片，这种暂停「现在或很快」就可行，主要风险是隐蔽规避、公开突破，以及训练效率提升带来的绕过。这是学术提案，不是政策，但它把「暂停」从口号推到了芯片设计和验证机制的层面，值得关注推理专用芯片方向的人留意。
